# Mini Project 1 🚀

This repository contains the source code for **Mini Project 1**, built with Python, modern LLM integration using the Groq API, and automated workflows.

---

## ✨ Features

- 🤖 **LLM Integration:** Powered by the Groq API for fast response generation.
- ⚙️ **Configurable Environment:** Uses local `.env` configuration to keep sensitive API keys protected.
- 📦 **Modular Architecture:** Organized codebase with clear separation of application logic, configurations, and scripts.
